# Edit the Page

## Pull Request
If you know how to use GitHub, you can edit the documentation while following the guidelines and make a Pull Request.

If you don't know how to use GitHub, follow the steps below:

## Starting with Edit
!["Edit this page" button at the bottom](./img/bottom.png)

At the bottom of each page, there is an "Edit the page" button. Click that button.<br>
If you are not already logged in to GitHub, you will be taken to a login page. Just login :)

### First Time Edit
![](./img/first_fork.png)

If it's your first time editing the page, you will see this page. In this case, click "Fork this repository" in the middle.

### Edit the page
![](./img/edit.png)

You can now edit the content of the page. Click "Preview" on the top left of the editor to see how the content will appear on the page. Available formatting options can be seen [here](./#markdown-format).

---

### Create an Edit Request
![](./img/commit.png)

When you are done with editing, click "Commit changes..." on the top right of the editor.

---

![](./img/create_commit.png)

Then you will see this window.<br>
In the "Commit message," you have to title your edit request. The title should make it easy to understand what your change is. You can add a more detailed description in the second box<br>
When done, click "Propose changes."

---

![](./img/create_pull_request_1.png)

![](./img/create_pull_request_2.png)

Finally, click "Create Pull Request."<br>

---

Now, it's done. You will have to wait for the review before your change gets applied to the page.<br>
If you want to see the review process, see [this next document](./review) :)
