# Iron Table & Values
It can often be confusing to know what to craft given a certain amount of Iron. This table can be used as a quick reference. Try to memorize this table; it will REALLY come in handy!

## Greater than or equal to 7 iron
This table is for situations where you have above 7 iron; the most common scenario.
For all values below, it is understood that you should craft an iron pickaxe, bucket, and flint & steel

| Amount | Best Crafts | Alternate 
| --- | --- | --- |
| 7   | None | N/A |
| 8   | Shovel | N/A | 
| 9   | Shears | Shovel + 1 |
| 10  | Shears + Shovel | Axe |
| 11  | Shears + Shovel + 1 | Axe + Shovel<sup>*</sup> |
| 12  | Shears + Axe | Axe + Shovel + 1<sup>*</sup> |
| 13  | Shears + Axe + Shovel | N/A |
| 14  | Shears + Axe + Shovel + 1 | N/A |
| 15  | Shears + Axe + Shovel + Sword | <s>Sword</s> → Pressure Plate<sup>***</sup> |
| 21  | Shears + Axe + Shovel + Sword + Doors <sup>**</sup> | N/A |

### Some notes and practices
- For seeds where you obtain TNT, the best practice is to go with the option that does not include shears, if you can make an extra tool. This is because exploding a TNT on the island/land will give you enough blocks for the run.

- Based on how much gold you get, you may choose to omit the axe or shovel crafts, as gold tools are faster. However, you may need to craft iron tools later in the run.

### Clarifications
<sup>*</sup>If you have TNT, this may be a smarter play, as you can avoid having to mine stone alltogether.</p>

<sup>**</sup>Crafting iron doors is a personal choice. Most runners will just stick to wooden doors and overlap the craft with the boat. Saving iron may be useful later for extra pickaxes and axes.

<sup>***</sup>You should only craft pressure plates if you have TNT.

## Less than 7 Iron
This table is for situations when you have less than 7 iron. These situations will only appear in ruined portal seeds.
Since all ruined portal seeds are guaranteed a light, cases with only 1, 2 or extra iron will not be listed as needing to craft a flint & steel.
When deciding between a bucket and a pickaxe, make a bucket if the portal is not a simple completion (only placing obsidian). Otherwise, craft a pixkace.

| Amount | Crafts | Alternative |
| --- | --- | --- |
| 1 | none | Shovel |
| 2 | none | Shovel + 1 |
| 3 | Bucket | Pickaxe |
| 4 | Bucket + 1 | Pickaxe + 1 |
| 5 | Bucket + Shovel + 1| Pickaxe + Shovel + 1 |
| 6 | Bucket + Pickaxe | N/A |
